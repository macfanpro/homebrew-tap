# hongyukeji Homebrew tap

Independent releases maintained by hongyukeji.

```bash
brew tap hongyukeji/tap
brew install thermalforgepro
sudo thermalforgepro install
```

For migration, updates and removal, see [ThermalForgePro](https://github.com/hongyukeji/ThermalForgePro).

The formula builds the tagged source and bundles the CLI, app and license notices. Root service installation is explicit; Homebrew never runs privileged setup inside its build sandbox.
